# Advanced Java Programming Laboratory (ADJ Lab) - College Project

A comprehensive collection of **Advanced Java Programming** laboratory practicals, exercises, and projects covering GUI development, Client-Server socket programming, JDBC database connectivity, Remote Method Invocation (RMI), Servlets, and a full-stack Capstone Project.

---

## 📑 Repository Structure & Index of Experiments

All source code and detailed documentation are organized inside [`adjrepo-main/`](adjrepo-main/):

| Exp No. | Experiment Title | Core Technologies | Directory |
|:---:|---|---|---|
| **01** | **Student Registration GUI Form** | Java Swing, AWT, Event Handling | [`adjrepo-main/exp1/`](adjrepo-main/exp1/) |
| **02** | **MVC Pattern Calculator Application** | Java Swing, MVC Architecture | [`adjrepo-main/calc/`](adjrepo-main/calc/) |
| **03** | **TCP Socket Client-Server Echo System** | Java Networking (`java.net`), Sockets, I/O Streams | [`adjrepo-main/server-client/`](adjrepo-main/server-client/) |
| **04** | **Database Connectivity & SQL Operations (JDBC)** | JDBC 4.2, MySQL, PreparedStatements | [`adjrepo-main/jdbc/exp3/`](adjrepo-main/jdbc/exp3/) |
| **05** | **Integrated GUI with Database Storage** | Swing GUI, JDBC, MySQL, Input Validation | [`adjrepo-main/strjdbc/`](adjrepo-main/strjdbc/) |
| **06** | **Distributed Computing via Java RMI** | Java RMI, Remote Interfaces, RMI Registry | [`adjrepo-main/Remote-Method-Invocation/`](adjrepo-main/Remote-Method-Invocation/) |
| **07** | **Servlet Container & Web Server Deployment** | Apache Tomcat 9, WAR Deployment, Web XML | [`adjrepo-main/apache-tomcat-9.0.121/`](adjrepo-main/apache-tomcat-9.0.121/) |
| **08** | **Java Web Development with Servlets, Filters, and Listeners** | Jakarta EE Servlet API, Session Tracking, Filters | [`adjrepo-main/servent/`](adjrepo-main/servent/) |
| **09** | **Full-Stack Enterprise E-Commerce Platform (BikeIsNice)** | Jakarta EE 11, Servlets 6.1, JSP 3.1, JSTL, MySQL DAO, Swing Desktop Admin, Sockets & RMI | [`adjrepo-main/BikeIsNice/`](adjrepo-main/BikeIsNice/) |

---

## 🛠️ Prerequisites & Setup

- **JDK**: Java Development Kit 17 or 21+
- **Database**: MySQL 8.0+
- **Build Tool**: Apache Maven 3.8+
- **Web Server**: Apache Tomcat 9.0.x (bundled in `adjrepo-main/apache-tomcat-9.0.121/`)

For in-depth documentation, compilation commands, and execution steps for each experiment, see the [Detailed Lab Documentation](adjrepo-main/README.md).
